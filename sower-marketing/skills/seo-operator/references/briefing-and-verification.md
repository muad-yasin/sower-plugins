# Briefing an agent for SEO work, and checking what comes back

*Open this file before you brief an agent on SEO or content work, and before you accept what it returns. SKILL.md sections 4 and 5 hold the rules; this file holds the template, the split between agent and person, and how each check is run.*

**Grades.** **I** = inferred, with the reason in the sentence. Where each line comes from: `evidence.md`, its section on this file.

## The brief

A topic name alone leaves the writer, a person or a model, with nothing that only this site knows (I; SKILL.md section 4). Every brief, whether it goes to an agent or to the drafting skill where the writer plugin is installed, carries four parts:

1. **The real question.** Not a keyword: the question a person would type into a search box or ask an assistant. "Best cozy shop game offline mechanics" is a keyword; "what happens to my plants while I'm offline?" is a question. Build the brief around the second.
2. **The one fact only this site has.** The reason this page should exist beside the ten others that already answer the question: a real build decision, a number from running the thing, a question real users asked more than once, a real mistake and what it cost. If the line is empty, the brief is not ready: find the fact before you hand the topic over, not after.
3. **The limits, each with what to do instead.** A limit alone tells the writer what to avoid and not what to produce, so each one names its replacement:
   - a number only with its source and its date, and none where there is no source;
   - the answer in the first lines, instead of an opening paragraph about the topic in general or a first sentence that repeats the question;
   - a plain claim where the evidence holds and a stated doubt where it does not, instead of a hedge on every sentence;
   - a competitor named only with a source a reader can check.
4. **The internal links.** Which pages of the same cluster this piece links to, and which existing pages get a link to it. Decide them yourself: an agent does not know which of your pages matter most, so its links follow the text in front of it, not your plan (I).

## What to hand to an agent, and what to keep

**An agent may do, with the checks below before anything is published:**
- an inventory of the site's content: what exists, what is thin, what repeats;
- keyword and competitor research, as material for a person's decision, not as the decision;
- a draft from an approved brief whose four parts a person supplied;
- a first review of a draft that lists unsupported claims, missing sources, vague headings, structured data that does not match the page and broken internal links, as a list to act on, not a gate that blocks without saying why.

**A person keeps:**
- which topics are worth the investment, and why: the judgement this skill exists for;
- the voice and the point of view;
- the first-hand fact itself (an agent can help shape one the person supplies; it cannot supply it);
- the decision to publish.

## The checks, and how to run each

A fabricated SEO report and a true one read alike: confident, specific, well ordered, and neither flags itself. So each check is mechanical, never "this looks thorough".

- **Read before write.** Research, audits and drafts need read access only. Write or publish access is granted for one output at a time, by a person who has looked at it, never as a standing permission an agent keeps across sessions.
- **Every number against its source.** Each figure, citation or "competitors do X" in an agent's output is checked against the source it names before it ships. A figure whose source does not say it, or that names no source, is treated as false (SKILL.md section 5).
- **The artifact, not the report.** "Structured data added" is a claim; the page loaded and its structured data run through a validator is a fact. "Internal links added" is a claim; following each link is a fact. Check what was published, not the account of what was done.
- **A sample audit on a schedule.** A page that was right when written can be wrong a quarter later: a competitor changed, a fact aged, a claim stopped being true. Re-check a rotating sample of published pages at set intervals, not only when the work was commissioned.

## Where this does not work well

For a genuinely specialised topic, an agent's draft plus an expert's rewrite can cost nearly as much time as the expert writing from scratch, because the rewrite comes close to a full one (I). When that is the case, say so in the report instead of saying the agent "handled" the topic.
